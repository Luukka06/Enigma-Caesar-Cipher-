# Caesar Cipher

A simple C++ console program that encodes and decodes text using the Caesar Cipher technique.

# Features
- Encode text using a custom shift value
- Decode previously encoded text
- Supports uppercase and lowercase Latin letters
- Interactive console interface
- Enter q to quit
# How it works

- The program shifts each letter by the specified number of positions in the alphabet.

-> For example, with a shift of 3:

-> Hello → Khoor

- The same shift can be used to decode the text back to its original form.

# Technologies
- C++
- Standard Library (iostream, string)
# Usage
- Run the program.
- Enter a passphrase.
- Choose 1 for Encode or 2 for Decode.
- Enter the shift value.
- View the result.
